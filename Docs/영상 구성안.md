## S2. 게임 개요 (카드)

| 항목 | 자막 |
|---|---|
| 게임 제목 | One Weapon (가제) |
| 장르 | 2D 횡스크롤 액션 (스테이지 클리어형, 보스전) |
| 컨셉 | 하나뿐인 무기를 던져 싸우고, 튕겨 나간 무기를 주워 다시 던진다 |
| 핵심 재미 (한 줄) | **"던진 무기를 되찾는 순간의 판단"** |

- 보조 자막: 무기가 하나뿐이라 던지는 순간 무방비가 되고, 되찾아야 다시 싸울 수 있다.
- 화면: 시작 화면(ONE WEAPON)을 3초 보여 주고 카드를 겹친다.

## S3. 조작 방법 (카드 + 시연)

| 입력 | 동작 |
|---|---|
| A / D | 좌우 이동 |
| Space | 점프 |
| 마우스 이동 | 조준 |
| 마우스 좌클릭 | 무기 던지기 |
| Shift / 마우스 우클릭 | 마우스 방향 대쉬 (3회 충전, 연타 가능) |
| Q | 던진 무기 회수 (룬의 동굴에서 룬을 먹은 뒤, 쿨타임 4초) |
| R / Esc | 다시 시작 / 일시정지 메뉴 |

- 시연 장면 3개(각 5초 안팎): ① 조준해서 던지기 ② 대쉬 연속 사용 ③ Q 회수.
- 시작 화면의 "조작 안내" 패널을 같이 보여 준다.

## S4. 핵심 플레이 화면 (실제 플레이, 자막은 흐름 설명)

| 구간 | 자막 |
|---|---|
| 스테이지 1 (전초기지) | 낮은 지형에서 몬스터 12마리를 처치하면 출구가 열린다 |
| 룬의 동굴 | 회수의 룬을 먹으면 Q 회수가 열린다 (설명 카드) |
| 스테이지 2 (성채) | 높은 성벽과 탑을 오르내리며 몬스터 15마리와 싸운다 |
| 보스 · 대지의 파수꾼 | 컷신 → 돌진·내려찍기 → 체력 절반에서 광분 → 처치 연출 |

## S5. 주요 기능 및 시스템 (직접 구현, 동작 화면과 함께)

| # | 기능 | 보여 줄 장면 | 자막 |
|---|---|---|---|
| 1 | 투척과 튕김 물리 | 벽과 적에 맞고 튕기는 무기 | 맞으면 랜덤 각도로 반사되고, 튕겨 다니는 중에도 적에게 피해를 준다 |
| 2 | 대쉬 | 연속 대쉬 3번 | 3회 충전, 대쉬 중 무적, 연타하면 이어서 나간다 |
| 3 | 회수 스킬 | 멀리 떨어진 무기를 Q로 회수하며 적을 맞힘 | 돌아오는 길의 적에게도 피해를 주고 하늘색 궤적이 남는다 |
| 4 | 몬스터 4종 | 졸병·정예·비행·슈터 | 추적하고 뛰어오르고, 슈터는 예고 뒤 조준 사격한다 |
| 5 | 보스 연출 | 바위 컷신, 광분, 처치 | 바위가 깨지며 등장, 체력 절반에서 광분(돌진 2연속·충격파 2번), 슬로모션 처치 |
| 6 | 스테이지 구조와 UI | 출구 잠김 표시, HUD, 설명 카드 | 몬스터를 모두 잡아야 출구가 열리고, 모든 UI를 코드로 직접 그렸다 |

- 부가: 타격 이펙트(불꽃·파편·화면 흔들림)는 기능 1~3 장면에 함께 보인다.

## S6. 시작부터 종료까지

시작 화면(Enter) → 스테이지 1 → 룬의 동굴 → 스테이지 2 → 보스 → **클리어 화면(클리어 시간)**.
- 자막: 목표는 보스를 쓰러뜨리는 것이고, 체력이 0이 되면 게임 오버, R 키로 처음부터 다시 시작한다.
- 게임 오버 화면과 재시작 장면을 5초 포함한다.

### 개발 중 겪은 문제와 해결 (실제로 있었던 일)

| # | 문제 | 해결 |
|---|---|---|
| 1 | 튕겨 나간 무기를 줍기 힘들다 | 회수 스킬(Q)과 회수 피해 추가, 스테이지 1을 낮은 지형으로 재구성, 구덩이와 좁은 틈 제거(맵 검증 규칙으로 막음) |
| 2 | 무기를 빠르게 던지니 튕김도 더 멀리 간다 | 튕김 속도를 비행 속도와 분리해서 따로 정함 |
| 3 | 몬스터가 늦게 나타나 이동 직후 바로 맞는다 | 스테이지가 시작되는 순간 몬스터를 배치하고, 나타난 직후 0.75초는 접촉 피해 없음, 시작 후 1초 무적 |
| 4 | 대쉬를 연타하면 한 번만 나간다 | 대쉬 중에 누른 입력을 0.25초 기억해 이어서 실행, 충전 3회·1.0초 |
| 5 | 보스 판정이 몸보다 크게 느껴진다 | 그림을 분석해 위쪽 빈 공간을 덮던 판정 상자를 몸에 맞춰 줄임 |
| 6 | 클리어 시간이 영상보다 길다 | 시작 화면과 일시정지 시간까지 재던 것을 고쳐 시작 버튼부터 플레이 시간만 측정 |
| 7 | 발판을 밟고 싸우는 플레이가 거의 안 나온다 | 발판을 빼고 큰 지형 중심으로 맵을 다시 설계 |
